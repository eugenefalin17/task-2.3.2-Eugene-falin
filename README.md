# Практическая задача 2.3.2 — Vegetable Shop

Интернет-магазин овощей, созданный на React + TypeScript.

## Стек

- React
- TypeScript
- Vite
- Mantine
- Vitest
- React Testing Library

## Реализовано

- загрузка списка овощей через API;
- отображение Loader во время загрузки;
- карточки товаров;
- изменение количества товара;
- добавление товаров в корзину;
- изменение количества товаров в корзине;
- удаление товаров из корзины;
- подсчёт общего количества товаров;
- подсчёт общей стоимости;
- всплывающее окно корзины;
- адаптивная вёрстка;
- hover-состояния карточек;
- тесты компонентов и приложения.
